# Current Bet

## Belief

If the public install works and three carefully selected parallel senior ICs
receive a short pain-led invitation, at least one will use Monkeypuzzle on a
real repository and reveal whether isolation plus in-worktree stacking is a
meaningful workflow improvement.

## Smallest test

1. Publish a Homebrew-installable release.
2. Validate the ten-minute first-piece path on a clean machine.
3. Recruit twenty behavior-qualified prospects.
4. Screen at least five and onboard at most three.
5. Observe whether anyone begins a second piece within fourteen days.

## Success

One external repeat user and a documented before/after workflow.

## Failure that teaches us

- Qualified prospects decline because the pain is not important.
- Installation or concepts prevent real use.
- First use succeeds but nobody returns.
- Users value a different part of the product than isolation and stacking.

## Current blockers

- First release requires a dedicated fine-grained token for the public Homebrew tap.
- Public docs and homepage still need the post-refactor mental model.
- Prospect list has not been populated.
