# Design partner outreach

I’m building a small Git workflow tool for developers who keep several changes
moving at once. Each piece gets an isolated worktree, branch stacks remain
ordinary Git and PRs, and you open the workspace with whatever editor or coding
tool you already use.

I’m looking for three developers who already feel this problem to try it on a
real repository. I’ll help with the initial install, but I specifically need to
see where the workflow fails without insider knowledge. Would you be open to a
30-minute setup and using it for one week?

## Personalization requirement

Add one sentence referring to an observed public behavior or a prior
conversation. Never pretend to have observed pain that is only inferred.
